# Каталог фильмов - HSE NIS React Домашнее задание #1
- React-приложение каталога фильмов, построенное на TypeScript, Vite и Tailwind CSS. Этот проект позволяет пользователям просматривать, искать, фильтровать и управлять коллекцией фильмов.

## Функциональность
- Отображение фильмов: Просмотр фильмов в виде сетки или списка
- Поиск: Поиск фильмов по названию или году
- Фильтрация и сортировка:
- - Фильтр по избранным
- - Сортировка по году (по возрастанию/убыванию)
- - Сортировка по названию (А-Я/Я-А)
- - Управление избранным: Добавление/удаление фильмов в избранное
- Добавление новых фильмов: Интерфейс для добавления новых фильмов в коллекцию
- Адаптивный дизайн: Построен на Tailwind CSS для мобильных устройств

## Быстрый старт
```bash
docker-compose up --build -d   
```

## Структура проекта
```text
src/
├── components/
│   ├── movieCard.tsx          # Компонент карточки фильма
│   └── addNewMovieCard.tsx    # Компонент для добавления новых фильмов
├── api/
│   └── movies.ts              # API сервис для операций с фильмами
├── types/
│   └── Movie.tsx              # TypeScript определения типов
├── utils/
│   └── movieUtils.ts          # Вспомогательные функции для работы с фильмами
├── App.tsx                    # Главный компонент приложения
└── main.tsx                   # Точка входа приложения
```
